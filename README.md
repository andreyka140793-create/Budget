# Дзен-бюджет

Telegram Mini App для учёта финансов.

## Возможности

- Доходы / расходы, счета, копилки, лимиты, графики
- **SMS банка** — перешлите в бота → распознавание → подтверждение
- **Автокатегории** — Магнит, такси, аптеки и т.д.
- **Импорт CSV** + экспорт
- Переводы между счетами, свайп-удаление, тема Telegram, бэкап БД
- Напоминания бота (`/remind on`)

## Быстрый старт

```bash
cp .env.example .env
npm install
cd webapp && npm install && npm run build && cd ..
npm start
npm run bot
```

## SMS

Перешлите боту SMS вида:
`Покупка 1520р MAGNIT Баланс: 10480р`

Бот предложит категорию «Продукты» и кнопки Записать / Отмена.
